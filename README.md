# Kanbanly

A premium, dark glassmorphism **kanban board** that runs entirely in the browser.

- Drag & drop cards between Backlog / In Progress / Done
- Live progress bar and task counters
- Keyboard support (focus a card, use arrow keys, Delete to remove)
- Inline add-task forms per column
- Data persists in `localStorage` — no account, no backend

## Stack

Vanilla HTML + CSS + JavaScript. No frameworks, no CDN, no build step.

## Run

Open `index.html` in any modern browser, or visit the live demo.

## Files

- `index.html` — structure and semantic markup
- `css/styles.css` — dark premium theme, glassmorphism, glow, animations
- `js/main.js` — board state, rendering, drag & drop, persistence
